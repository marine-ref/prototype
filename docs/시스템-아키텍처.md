## 데이터 소스

| 소스 | 내용 |
|------|------|
| 기술교범 | IETM·구조/정비절차·부품정보 |
| 고장사례 DB | 증상·원인·조치·재발 |
| 기체 상태 | 진동·온도·압력·유량 · PHM |
| 정비·운용 | 비행기록·점검결과 |
| 3D/도면 | 수리온 형상·부품 위치 |

## AI 엔진

1. **교범 지능형 검색 (RAG)** — 하이브리드 검색 · 출처 강제  
2. **유사 고장 분석** — 증상·부품·운용조건 유사도  
3. **PHM 상태분석** — 이상감지 · 진행도 · RUL  
4. **디지털트윈 연계** — 부위 매핑 · 색상 위험표시  
5. **정비 의사결정** — 우선순위 · 권고 작업지시  

## 외부 연동 (API, 후속)

- 정비정보체계 (ALIS/ILS)
- PHM 체계
- 영상처리 (VMS)
- 통합플랫폼 · 운용/비행기록

## 운용 제약

- **폐쇄망 On-Premise** (외부 LLM SaaS 불가)
- Edge(Jetson 등) 추론 옵션
- 권한·질의·분석·조치 이력 감사
