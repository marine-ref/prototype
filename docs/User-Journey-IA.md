# User Journey · IA

## 정비사 여정

```text
[1] 현황          기체·이상 알림 확인
[2] AI 어시스턴트  증상 질의 (텍스트·음성·사진)
[3] 통합 결과      DT 하이라이트 + 요약 카드
[4] 근거 확인      교범 / 유사사례 / PHM
[5] 정비 가이드    점검순서·작업지시·이력 기록
```

## 화면 IA

```text
/                 현황 대시보드
/assistant        One-Screen (챗 + DT + 요약)  ★핵심
/manuals          교범 검색·출처
/failures         유사 고장사례
/phm              PHM · RUL
/guide            정비 가이드 · 작업지시
/history          질의·조치 이력
```

## 시연 Drill-down

```text
현황 → AI 어시스턴트 → (탭) 교범|사례|PHM → 정비 가이드
```

사이드·상단 브레드크럼 순서는 동일하게 유지한다.
