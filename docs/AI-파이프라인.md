# AI 파이프라인

## 통합 흐름

```text
질의/센서입력
  → Orchestrator (의도·우선엔진)
  → [RAG | Case | PHM] 병렬
  → 결과 융합
  → Digital Twin 매핑
  → 권고조치 · 작업지시
```

## RAG (교범)

```text
교범 PDF → 청킹(절차 단위) → Embedding → Vector DB
질의 → Hybrid(의미+부품번호/고장코드) → Top-k
→ 근거 문단 + 장·절·페이지
→ 근거 없으면 답변 제한 (환각 방지)
```

## 유사 고장

```text
증상·부위·고장코드·운용조건
→ 사례 DB 유사도
→ 원인 · 점검순서 · 조치결과 · 재발여부
→ 교범 표준절차와 대조 표시
```

## PHM

```text
진동·온도·압력·영상/음향
→ 전처리·동기화·특징추출
→ 이상탐지 · 위험등급
→ 고장 진행도 · RUL · 권장 정비시점
```

## 디지털트윈

```text
부품 ID ↔ 3D/SVG 노드
상태등급 → 색상 (정상/주의/위험)
클릭 → 교범·사례·PHM·권고 동시 표시
```

## MVP mock 규칙

- 고정 시나리오: 엔진 오일 압력 저하 → 필터 점검/교체  
- 유사도·RUL·출처는 시연용 고정값 + 약간의 변동 가능
