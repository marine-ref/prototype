# 프로토타입 정의서

> 근거: `(붙임1) 해병대 AI 아이디어 시제품 제안서` · 시스템 구성도 최종이미지  
> 관점: **질의 → 근거 검색 → 상태진단 → 디지털트윈 가시화 → 조치 가이드**

---

## 1. 한 줄 결론

수리온 계열 **기술교범 + 고장사례 + 상태데이터**를 AI로 통합 분석하고,  
정비사가 **하나의 화면(One-Screen)** 에서 즉시 조회·판단할 수 있는 지능형 정비 어시스턴트 MVP.

---

## 2. As-is / To-be

| | As-is | To-be |
|--|-------|-------|
| 교범 | PDF 키워드, 10~20분 탐색 | RAG 자연어·출처(장·절·페이지) |
| 고장대응 | 개인 암묵지·수기 | 유사사례 DB + 조치이력 |
| 정비방식 | 사후조치 중심 | PHM 이상감지·RUL 예측 |
| 분석결과 | 수치·그래프 위주 | 디지털트윈 색상 가시화 |
| 체계 | 기능 분절 | 교범·사례·PHM·DT 통합 흐름 |

---

## 3. MVP 범위 (시제품)

| 구분 | 포함 | 비고 |
|------|------|------|
| 통합 UI | 텍스트 질의 · 음성/사진 입력(UI) · 결과 패널 | mock 응답 |
| 교범 RAG | 출처 표시 · 원문 링크 | Vector DB 연동은 Phase 2 |
| 유사 고장 | 유사도 · 원인 · 조치결과 | mock DB |
| PHM | 위험등급 · 진행도 · RUL | mock 시계열 |
| 디지털트윈 | 이상 부위 하이라이트 · 패널 연동 | 2D/SVG 프로토타입 |
| 정비가이드 | 권고 점검순서 · 작업지시 | 의사결정 엔진 mock |
| 보안 | 폐쇄망 가정 · 권한 UI | On-Prem 배포는 후속 |

---

## 4. 시연 시나리오 (고정)

```text
기체: Surion-KUH-01 (해병 정비대대)
증상: "엔진 오일 압력이 낮아."
AI:  가능 원인·점검절차 안내
DT:  엔진 오일계통 하이라이트 (위험 높음)
권고: 오일 필터 점검 및 교체
근거: 교범 엔진편 3장 2절 · 유사사례 2023-포항 · PHM RUL 18FH
```

---

## 5. 비목표 (이번 MVP 제외)

- 실기 비행데이터·실측 센서 실시간 연동
- 상용 ALIS/ILS 양방향 쓰기
- 실기 3D CAD 디지털트윈 엔진
- 폐쇄망 LLM 실배포 (구성·요구만 문서화)

---

## 6. 단계 로드맵

1. **데이터 기반** — 교범 청킹 · 사례 표준화 · 상태 샘플  
2. **기능별 AI** — RAG · 유사도 · PHM 모델  
3. **통합 시제품** — One-Screen · DT 연계 (← 현재)  
4. **폐쇄망 적용** — On-Prem LLM · 권한·이력  
5. **부대 실증** — 검색·진단·응답시간·현장성 검증
