# UI 현황 전달서

> 앱 경로: `marine-surion-ai/web`  
> 상태: **프론트 프로토타입 (목데이터)** — 실 AI·군 체계 미연결

## 1. 한 줄 요약

수리온 계열 정비를 위한 **One-Screen AI 어시스턴트**입니다.  
챗 질의 · 디지털트윈 하이라이트 · 교범/유사사례/PHM/가이드가 시연 흐름으로 연결됩니다.

## 3. 공통 레이아웃

* 좌측 고정 사이드바 (시연 흐름 1~6 + 이력)
* 상단 페이지 헤더 (제목·부제)
* 본문 상단 시연 브레드크럼 + **다음** 버튼
* 사이드바 순서 = 브레드크럼 순서

## 4. 화면 맵

```text
현황 (/)
 └─ AI 어시스턴트 (/assistant)  ★ One-Screen
      ├─ 교범 검색 (/manuals)
      ├─ 유사 고장 (/failures)
      ├─ PHM 상태 (/phm)
      └─ 정비 가이드 (/guide)
이력 (/history)
```

## 5. 화면별 UI

| 경로 | 구성 | 완성도 |
|------|------|--------|
| `/` | KPI · 기체 목록 · 시연 CTA | ✅ |
| `/assistant` | 챗 + SVG 디지털트윈 + 요약 카드 | ✅ 핵심 |
| `/manuals` | 교범 카드(장·절·페이지·발췌) | ✅ |
| `/failures` | 유사도·원인·조치·결과 | ✅ |
| `/phm` | 위험·RUL·센서 · 진행도 차트 | ✅ |
| `/guide` | 권고 + 단계별 점검순서 | ✅ |
| `/history` | 질의·분석·조치 테이블 | ✅ |
